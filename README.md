# 猜數字遊戲 (Web)

互動式網頁版猜數字遊戲。系統隨機產生 1~100 的整數，玩家透過瀏覽器猜測答案，並即時獲得「大了」或「小了」的提示。

## 功能

- 隨機產生 1–100 整數作為答案
- 輸入驗證（必須是 1–100 的整數）
- 即時提示：大了 / 小了 / 恭喜通過！
- 遊戲結束後顯示答案與本局猜測次數
- 成績統計：總局數、最少猜測次數、平均猜測次數、成功率
- 無外部依賴，僅使用 Python 標準庫

## 環境需求

- Python 3.8+

## 啟動方式

```bash
python app.py
```

開啟瀏覽器前往 [http://localhost:8080](http://localhost:8080)

## 專案結構

```
guess-number/
├── app.py              # Python HTTP 伺服器 + 遊戲邏輯
└── static/
    └── index.html      # 前端 HTML / CSS / JavaScript
```
